# Tant qu’il y aura des Épices

Application de gestion pour commerce de marché : ventes, stocks, clients, fidélité, pilotage et trésorerie.

## Sprint 1
- Authentification Supabase
- Lecture des produits et clients
- Recherche
- Ajout d’un produit
- Ajout d’un client

## Configuration locale
1. Copier `.env.example` en `.env`
2. Renseigner les variables Supabase publiques
3. `npm install`
4. `npm run dev`
